ComodaDesk - Interior & Exterior Design Landing Page

Overview:
----------
This project is a clean and elegant landing page built for ComodaDesk — a design studio offering interior and exterior design services along with product curation. The site is fully responsive, lightweight, and easy to customize.

Key Features:
-------------
- Modern minimalist layout with natural textures and elegant fonts
- Hero section with transparent overlay and prominent branding
- "About" section that describes ComodaDesk's mission and services
- Dedicated areas to showcase recent projects and featured products
- Fully transparent backgrounds to reflect a soft, sketch-style aesthetic
- Contact section with placeholders for real contact details (email, phone, location)
- Clear comment structure throughout the code to allow quick edits

Client Brief Integration:
--------------------------
The layout and design reflect the client's vision:
• A space to present visual inspiration and preliminary plans
• A curated selection of products (e.g. sofas, lighting, branded candles)
• A soft, refined style with a handcrafted feeling (implemented through subtle texture background and clean sections)

Customization:
--------------
- All images are located in the `/images` folder and can be easily replaced
- Text can be updated directly in HTML as each section is clearly marked
- Logo is included in vector format and styled for both header and hero sections
- Comments in the HTML indicate where the client should insert their own information (email, phone number, social links)

Tools Used:
-----------
- HTML5 & TailwindCSS 2.x
- Google Fonts (Poppins, Dancing Script)
- Optimized for modern browsers and devices
